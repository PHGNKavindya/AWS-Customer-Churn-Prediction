# AWS-Customer-Churn-Prediction
This project analyzes customer churn using machine learning and AWS services.

Amazon S3 is used to store customer datasets, AWS Glue manages the data catalog, and Amazon Athena is used to run SQL queries and analyze customer churn patterns.

The analysis focuses on churn rates and factors such as contract type, payment method, Internet service, customer tenure, and monthly charges.

Technologies: Python, SQL, Amazon S3, AWS Glue, Amazon Athena, and Machine Learning.
